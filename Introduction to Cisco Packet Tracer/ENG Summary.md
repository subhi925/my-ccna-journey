# Lesson 06: Introduction to Cisco Packet Tracer

## Overview
Cisco Packet Tracer is a visual simulation tool designed by Cisco that allows users to create network topologies, configure devices, and simulate network behavior in real-time or simulation mode.

## Key Concepts

### 1. Packet Tracer Interface & Environment
* **Workspace:**
  * **Logical Workspace:** Used for designing logical network topologies, connecting end devices, switches, and routers.
  * **Physical Workspace:** Simulates physical locations, cities, buildings, and wiring closets to visualize real-world physical constraints.
* **Modes:**
  * **Real-time Mode:** Simulates network traffic in real-time. Protocols respond immediately as they would in a real environment.
  * **Simulation Mode:** Allows step-by-step inspection of packets (PDUs) moving through the network, helping analyze headers and protocol behavior layer by layer.

### 2. Device Categories
* **End Devices:** PCs, Laptops, Servers, Printers, IP Phones.
* **Network Intermediary Devices:** Routers, Switches, Wireless Access Points, Firewalls.
* **Connections:** Straight-Through cables, Crossover cables, Fiber, Serial cables, and Console cables.

---

## Technical Glossary
* **Packet Tracer:** A network simulation tool developed by Cisco for learning and prototyping.
* **Logical View:** The visual representation of network devices based on their logical connections.
* **Physical View:** The visual representation of network hardware in physical buildings and racks.
* **Simulation Mode:** A mode in Packet Tracer to trace and analyze packet flow step-by-step.
* **PDU (Protocol Data Unit):** A unit of data specified in a protocol of a given layer of the OSI model.
